## Statuses

Every application has one of six statuses:

| Status | Meaning |
|---|---|
| Saved | You are interested and have not applied yet |
| Applied | Sent |
| Interviewing | A conversation is in progress |
| Offer | You have one |
| Rejected | They said no |
| Withdrawn | You pulled out |

Change a status from the list or from the application itself. Each change is dated and kept on the application's timeline.

## The applications list

**Applications** in the sidebar lists everything. Search by company or role, filter by status, and move through rows with <kbd>j</kbd> and <kbd>k</kbd> or the arrow keys; <kbd>Enter</kbd> opens the focused row.

## One application

Open a row to see everything about it:

- **Job description.** The posting as it was captured, kept because postings get taken down.
- **Notes.** Anything you write, in Markdown.
- **Timeline.** When it was added and from where, each status change, and each follow-up you log.
- **Details** you can edit: company, role, location, link.

On Pro, this is also where you build a [tailored CV](/docs/tailored-cv) for the posting.

## Home

Home opens on three numbers, each of which opens the list already filtered:

| Tile | What it counts |
|---|---|
| Ghosted | Applied over 14 days ago, still silent |
| Awaiting response | Applied within the last 14 days |
| In interview | Conversations currently open |

Below them are the charts: applications added each week, the pipeline by status, where your applications came from, and how long replies take.
